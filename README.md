Nuestro proyecto llamado "Queico" consiste en un asistente virtual representado por un queque caricaturesco, este fue creado con el propósito de ayudar emocionalmente a los estudiantes de enseñanza media con problemas emocionales como vendrían siendo el estrés, la depresión, ansiedad, y en algunos casos (aunque no sea un problema emocional, también se tiene en cuenta para nuetro proyecto), el TDAH.
Las herramientras que principalmente utilizamos para nuestro proyecto vendrían siendo: Blender, VSC (Visual Studio Code), GitHub (para subir los codigos que realizabamos), ChatGPT (Nuestro codigo estaba conectado con él), Python y OpenCV.
